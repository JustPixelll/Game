# Changelog

## 1.0.0 · First playable release

Original Bramblehaven town simulation, isometric canvas world, production and neighbourhood systems, guild roster, seven expedition regions, collection, charter campaign, research and legacy. Responsive phone/desktop controls; optional procedural sound; local saves and portable backups; offline Android shell and portable HTML edition.

Pre-release checks fixed touch placement occlusion, interface refresh racing pointer input, hero sprite animation IDs, non-finite external reward input, inherited-object-key validation, loss of above-capacity inventory, and native background/foreground catch-up handling.
